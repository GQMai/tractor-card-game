# 阿春拖拉机 · 现代重制版

一款可在 Windows 7 SP1 上运行的四人拖拉机（升级）桌面游戏，使用 Electron 22.3.27 构建。
牌型规则与大小判定对齐原版程序，内置三名电脑玩家，可配置 1~4 副牌。

## 特性

- **Windows 7 兼容**：Electron 22.3.27（最后支持 Win7 SP1 的版本），关闭硬件加速
- **多副牌**：1 / 2 / 3 / 4 副可选，奇数副 6 张底牌、偶数副 8 张底牌
- **完整牌型**：单张、对子、三条、四条、拖拉机、推土机、连四条、甩牌
- **亮主与反主**：级牌、双王可亮主；无主必须用两张**相同**的王（两张大/两张小王，大小王不可混搭）
- **甩牌**：只看决胜段（最大结构）是否必大，其余小牌被盖过不影响；副牌缺门时也能甩
- **电脑 AI**：按胜率决定出分、终局保留对子与小王的散主垫牌策略、按收益决定是否毙牌
- **老人友好**：手牌与出牌区放大、按钮居中、悬停不抖动

## 快速开始

```bash
npm install
npm start        # 开发运行
npm test         # 规则内核自检 + 160 局 AI 自博弈
npm run dist     # 打包便携版到 dist\TractorWin7
```

打包产物为 `dist\TractorWin7\` 整个文件夹（约 196 MB），**必须整包分发**。
只复制 `Tractor.exe` 会因为缺少 `resources\app` 中的界面资源而无法启动。

## 运行环境

- Windows 7 SP1 64 位及以上（Windows 10 / 11 同样可用）
- 建议安装 SHA-2 补丁 `KB4474419` 与通用 C 运行库 `KB2999226`
- 免安装，无需 .NET / Node.js；游戏设置保存在 `%APPDATA%` 目录

## 规则要点

- 牌序：大王 > 小王 > 主级牌 > 副级牌 > A > K > … > 2
- 主牌 = 大小王 + 主花色 + 四门级牌
- 比大小必须结构相同：对子压对子、三条压三条、四条压四条、同型链压同型链；
  两张单牌压不住对子，两对压不住四条
- 跟牌：有该门必须跟该门；不足时先出完该门再垫牌；缺门且有同型主牌才能毙
- 底牌加分 = 底分 × 副数 × 末墩张数
- 无人亮主时翻底定主
